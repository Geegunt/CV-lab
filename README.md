## Описание работы

Цель лабораторной работы — извлечь разметку объектов из видео с уже нарисованными bounding box'ами и восстановить её в стандартном формате COCO.

В работе используется два видео:

- `input.mp4` — исходное видео без bounding box'ов;
- `output.mp4` — демонстрационное видео с визуализированной разметкой.

Также используется оригинальная разметка, загружаемая по ссылке из задания. Она применяется для оценки качества восстановленных bounding box'ов по метрике IoU.

Дополнительно на основе восстановленной разметки обучается модель детекции объектов из `torchvision.models.detection`, после чего качество модели оценивается по mAP.
